# Security Policy

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/HanielCota/SellBridge/security/advisories/new).

Include a description of the issue, steps to reproduce, the affected area (for example: authentication, marketplace connectors, webhooks, multi-tenant data access), and the potential impact.

You can expect an acknowledgement within 3 business days and a status update within 10 business days. Once the issue is fixed, you will be credited in the advisory unless you prefer to stay anonymous.
